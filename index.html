Small, specific, infuriating problems — the kind you solve by hand every few weeks and never think to look up. One tool per problem. No signup, no upload, nothing leaves your browser.

CORS · HTTP · Debugging

CORS Error Decoder

Paste the CORS error your browser printed. Get the cause in plain English, which machine is at fault, and copy-paste config for your actual server — with your real origin filled in.

 CSP · Security

CSP Violation Decoder

Paste your Content-Security-Policy console errors and get the smallest policy that unblocks them — nonces and hashes before unsafe-inline, with a grade showing what each concession costs.

 HTTP · Caching

Cache-Control Simulator

Paste your caching headers and see what the browser and a CDN actually do on a revisit, a reload and after expiry — plus the directives that are quietly cancelling each other out.

 Git · Debugging

Why isn't my .gitignore working?

See which single line decides each file, catch the re-include that silently does nothing, and find out when the real answer is that git already tracks the file.

 Regex · Portability

Will my regex work everywhere?

It passes in regex101 and fails in Go. See which engines support what you used, get the rewrite where one exists, and find out where none does.

 CSV · Data

CSV Diff by key

A text diff calls every line changed the moment an export reorders rows. This matches rows by a key column and shows only the cells that genuinely differ.

 CSV · Data integrity

Will Excel break my CSV?

Drop a CSV and see every cell Excel will silently destroy — gene names turned into dates, stripped leading zeros, IDs mangled into scientific notation. Then download a version that survives.

 Text · Unicode

Invisible Character X-Ray

Two identical-looking strings that aren't equal. Paste the text and every zero-width space, non-breaking space, bidi override and homoglyph lights up — then strip them in one click.

 JSON · CSV

Nested JSON to CSV

Flatten deeply nested API responses into a real spreadsheet. Choose whether arrays get joined, indexed, or exploded into one row each — the unnest most converters don't offer.

 Files · Cross-platform

Will this filename break?

Check names against Windows, macOS, Linux, SharePoint, S3 and Git. Reserved words, illegal characters, path limits, and the case and Unicode collisions that only appear on someone else's machine.

 Cron · Ops

Cron Collision Inspector

Paste a whole crontab. Find the jobs landing on the same minute, the ones daylight saving silently skips, and the ones that never run at all.

What this is

Most software problems worth solving are enormous. These are not those. Each of these tools fixes one small thing that wastes twenty minutes and a bit of your goodwill — the CSV that arrives with the ZIP codes already destroyed, the string that will not match itself, the crontab where everything fires at 3am.

Every tool here follows the same rules:

  • One job. One input, one transformation, one useful result.
  • No account. The tool is the page. There is nothing to sign up for.
  • Nothing is uploaded. Every tool runs entirely in your browser — no server, no network request, no telemetry. You can disconnect from the internet and they still work.
  • The output is the product. Copy it, download it, or copy a report you can paste straight back to whoever caused the problem.

Why "papercuts"?

None of these problems is a crisis. Each one is a small cut you keep re-opening because it was never worth a whole afternoon to fix properly. Collectively they are most of a working week a year.

Are these really free?

Yes, and there is no catch to explain: since everything runs client-side there is nothing to meter and almost nothing to pay for. No ads, no tracking, no email capture.
